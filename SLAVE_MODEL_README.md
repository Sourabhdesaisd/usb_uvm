# USB PHY slave/peer model

`phy_bfm_agent/usb_slave_model.sv` extends the UART-style phy_bfm agent. The device driver accepts `usb_slave_packet_seq` (LS/FS), `usb_slave_reset_seq` and `usb_slave_response_seq`. Packet sequence constructs speed-specific J/K SYNC, phy_bfmizes bytes LSB first, NRZI encodes, inserts a zero after every six consecutive decoded ones including the final SYNC one, and drives legal or injected SE1/SE0/EOP segments. The peer monitor records line ownership and resolved levels. `phy_bfm_agent/usb_slave_model.sv` independently examines the DUT's TX pins, builds expected symbols from accepted SIE bytes, checks exact line and timing, then reconstructs wire bytes for the scoreboard. `env/usb_phy_scb.sv` checks both paths.

The testbench models an external analog receiver that suppresses its enable during local TX. `analog_phy_bfm` is J=1/K=0 for LS/FS. Only one side owns the line at a time; the bus monitor reports contention. HS is supported on TX (one bit per 480 MHz clock, 32-symbol SYNC, 8 or SOF 40-symbol EOP). Supplied CDR does not receive HS and no external HS bypass exists. Fault modes cover SE1, missing stuffed bit, overlong SE0 and bad SYNC; a separate test adds trailing dribble bits. Testbench does not emulate SIE packet PID/CRC or an analog waveform.

All peer sequence classes and the TX wire checker are defined inside the single `phy_bfm_agent/usb_slave_model.sv` source file; there are no separate packet, reset, response or checker source files. `send_hs_line_packet()` can emit specification-shaped HS line traffic (32-symbol SYNC, 1 clock per bit, unstuffed 8/40-symbol EOP), but cannot check DUT HS RX without an HS receiver.
